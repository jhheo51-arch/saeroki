# 새록이 Saeroki

<img src="assets/saeroki-character-v02.png" alt="찻잎 귀와 새싹 꼬리, 기록장 주머니를 가진 새록이 캐릭터" width="320">

새록이는 관심 분야에서 아직 알지 못한 항목을 발견하고, 근거와 함께 소수만 추천하는 개인 AI 에이전트 프로젝트입니다.

`새`는 새로운 발견, `록`은 초록과 기록을 뜻합니다.

> 새록이, 한 잔의 차처럼 건네는 새로운 발견

## 현재 상태

- 제품군과 16개 후보를 정리한 PRD v01 작성
- Claude와 Codex가 함께 읽는 공통 행동 원칙 작성
- 첫 기능인 콘텐츠 개인화 추천의 최소 Python 코드와 검사 작성
- 외부 AI 모델, 음악 서비스, 뉴스레터 서비스는 아직 연결하지 않음

## 문서

- [제품군 PRD](docs/PRD-v01.md)
- [공통 에이전트 원칙](AGENT-SPEC.md)

## 최소 코드 확인

Python이 설치된 터미널에서 다음 명령을 실행합니다.

```powershell
python -m unittest -v
```

검사는 이미 아는 항목과 제외 태그를 거르는지, 인기도 자료가 없을 때 덜 유명하다고 단정하지 않는지 확인합니다.

## 아직 하지 않은 것

- 실제 사용자 취향 자료 수집
- RSS, 날씨, 음악 서비스와의 연결
- Claude 또는 OpenAI API 연결
- Agno 도입
- 금융과 법률 분야의 실제 판단 기능

공통 기반이 실제 첫 추천 흐름에서 부족할 때만 다음 기술을 추가합니다.
