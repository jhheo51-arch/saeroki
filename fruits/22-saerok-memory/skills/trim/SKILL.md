# 목차 줄 요약 제안

이 스킬 폴더의 두 단계 위가 플러그인 폴더이고, 실행 스크립트는 `<플러그인 폴더>/bin/saerok-memory`입니다.

1. `bash "<플러그인 폴더>/bin/saerok-memory" suggest --list`로 목차 줄 후보(JSON)를 받습니다. `limit`은 목차 전체를 4,000바이트 안에 넣으려면 줄마다 지켜야 할 글자 수이고, `budget_only`가 true면 150자는 넘지 않지만 예산 때문에 줄일 줄입니다.
2. 후보마다 `before`를 읽고, `- [제목](파일) — 설명` 꼴의 한 줄을 **`limit`자 안**으로 씁니다. 어떤 경우에도 150자는 넘지 않습니다.
   - 제목과 파일 이름은 그대로 둡니다.
   - 설명에는 "언제 이 기억을 열어야 하는지" 알 수 있는 핵심만 남깁니다. 날짜별 진행 기록, 커밋 해시는 뺍니다(원래 설명 전체는 적용할 때 기억 파일 본문 끝으로 옮겨집니다).
   - 원문에 없는 사실을 만들지 않습니다.
3. 후보마다 저장합니다.

   ```bash
   bash "<플러그인 폴더>/bin/saerok-memory" suggest --id "<id>" --text "<제안 줄>"
   ```

4. 저장한 제안을 원문과 나란히 표로 보여 주고, 적용은 대시보드 후보 탭에서 사용자가 직접 누른다고 알립니다. 이 스킬에서 MEMORY.md를 직접 고치지 않습니다.
