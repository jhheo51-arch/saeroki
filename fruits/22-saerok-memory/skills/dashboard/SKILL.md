# 새록 가지치기 대시보드

이 스킬 폴더의 두 단계 위가 플러그인 폴더이고, 실행 스크립트는 `<플러그인 폴더>/bin/saerok-memory`입니다.

1. 대시보드를 원하면 아래 명령을 **백그라운드**로 실행하고, `http://127.0.0.1:8738`을 열었다고 알립니다. 서버는 사용자가 끝낼 때까지 켜 둡니다.

   ```bash
   bash "<플러그인 폴더>/bin/saerok-memory" serve
   ```

2. 요약만 원하면 `bash "<플러그인 폴더>/bin/saerok-memory" status`를 실행해 한국어로 짧게 정리합니다.
3. 정리는 사용자가 대시보드에서 버튼을 눌러야만 합니다. Claude가 기억 파일을 직접 옮기거나, 파일을 휴지통으로 보내거나, 휴지통을 비우지 않습니다.
4. 목차 줄 요약 문장이 필요하면 `/saerok-memory:trim`을 안내합니다.
