# 🌸 22 새록 가지치기

Claude Code가 세션마다 읽는 기억 목차(`MEMORY.md`)가 길어지고, 작업 폴더에 옛 버전 파일이, `~/.claude/projects`에 세션 기록이 쌓이는 것을 찾아 줄이는 정리 도우미입니다. 스스로 바꾸는 것은 없습니다. 대시보드에서 내가 누른 것만 적용하고, 바꾸기 전에 백업하며, 되돌릴 수 있습니다.

- 설계: [PRD v2.3](../../docs/PRD-v2.3.md)
- 공통 원칙: [AGENT-SPEC.md](../../AGENT-SPEC.md)
- 외부 라이브러리 없이 Python 표준 라이브러리만 씁니다.

```text
새록 가지치기: MEMORY.md가 9,765바이트(기준 4,000), 150자 넘는 줄 5개입니다. /saerok-memory:dashboard에서 줄일 수 있습니다.
```

## 왜 필요한가

`MEMORY.md`는 대화를 열 때마다 컨텍스트에 그대로 실립니다. 2026-11-04 이 PC를 검사해 보니 목차 하나가 9,765바이트였고, 가장 긴 줄은 963자였습니다. 한 줄에 진행 기록을 계속 덧붙이면서 목차가 본문 노릇을 하고 있었습니다. 같은 날 세션 기록은 171개, 3.6GB였습니다.

## 설치와 실행

### Claude Code 플러그인(추천)

```text
/plugin marketplace add jhheo51-arch/saeroki
/plugin install saerok-memory@saeroki
```

대시보드는 `/saerok-memory:dashboard`로 엽니다. 긴 목차 줄의 요약 문장을 Claude에게 받고 싶으면 `/saerok-memory:trim`을 씁니다. Python 3.10 이상이 필요합니다.

### 이 저장소에서 직접

```powershell
python -m pip install -e fruits/22-saerok-memory
```

```powershell
saerok-memory              # 대시보드 열기(http://127.0.0.1:8738)
saerok-memory status       # 터미널 요약
saerok-memory suggest --list
```

## 대시보드

| 탭 | 보여 주는 것 |
|---|---|
| 지금 | 목차 합계 바이트, 가장 긴 목차 줄, 옛 버전과 세션 기록 후보, 프로젝트별 목차 크기와 가장 긴 줄, 목차 알림 훅 켜기·끄기 |
| 후보 | 목차 예산 상자(지금 바이트 → 고른 줄 적용 뒤 바이트, 모두 고르기, 한 번에 적용), 목차 줄(원문과 고칠 줄을 나란히, 글자 수와 예산 글자 수 표시), 끝난 기억, 확인만 할 것, 옛 버전 파일, 오래된 세션 기록 |
| 기록 | 적용한 조치 수, 되돌린 비율(목표 10% 이하), 목차에서 줄인 바이트, 휴지통으로 보낸 용량, 그리고 조치별 되돌리기 |

## 무엇을 후보로 보는가

| 종류 | 기준 | 버튼 |
|---|---|---|
| 긴 목차 줄 | 150자 넘는 줄. 앞에서부터 쉼표 마디(괄호 안 쉼표는 나누지 않음)를 남기는 제안, 또는 `/saerok-memory:trim`이 남긴 AI 요약 | 적용: 목차 줄을 바꾸고 원래 설명은 그 기억 파일 끝 `## 목차에서 옮긴 기록`으로 옮김 |
| 목차 예산 | 목차가 4,000바이트를 넘으면, 줄마다 몇 자 안으로 줄여야 기준 안에 드는지(150자부터 5자씩, 60자까지) 계산해 그 길이를 넘는 줄 | 체크한 줄을 한 번에 적용. 기록은 한 건, 되돌리기도 한 번 |
| 끝난 기억 | 목차나 설명에 적힌 마감·중단 날짜에서 30일, 파일 수정에서도 30일 넘게 지남 | `_archive/`로 옮기고 목차 줄을 뺌. 휴지통으로 보내지 않음 |
| 확인만 할 것 | 본문의 경로가 지금 없음, 목차와 파일이 어긋남, 두 기억이 같은 위치를 적음 | 없음. 보여 주기만 함 |
| 옛 버전 파일 | 같은 폴더, 같은 이름의 `_v1`, `_v2` 묶음에서 최신 두 버전을 뺀 것 중 14일 넘게 안 고친 것 | 고른 것을 Windows 휴지통으로 |
| 오래된 세션 기록 | 30일 넘게 바뀌지 않은 `.jsonl`. 30분 안에 바뀐 기록은 열려 있다고 보고 늘 뺌 | 숫자 집계를 먼저 남긴 뒤 Windows 휴지통으로 |

옛 버전 파일에서 git이 추적하는 파일, 이름에 `제출`·`최종`·`final`이 들어간 파일, 바탕화면 아래 파일은 보호합니다.

## 지키는 것

- 영구 삭제와 휴지통 비우기는 하지 않습니다. 비우기는 직접 합니다.
- 기억 파일은 지우지 않고 `_archive/`로만 옮깁니다. 바꾸기 전에 `~/.saerok/memory/backup/<날짜>/`에 복사해 둡니다.
- 되돌리기는 적용한 뒤 아무도 다시 고치지 않은 파일만 복원합니다. 휴지통으로 보낸 것은 Windows 휴지통에서 복원합니다.
- 세션 기록을 버릴 때는 응답 수, 처리 토큰, 최대 컨텍스트, 첫·마지막 시각만 `~/.saerok/memory/session-archive.jsonl`에 남깁니다. 대화 원문은 남기지 않습니다.
- AI는 요약 문장을 제안하는 데만 씁니다. `/saerok-memory:trim`은 `MEMORY.md`를 직접 고치지 않고 제안만 저장하며, 대시보드에서 원문과 나란히 보고 적용합니다.
- 서버는 `127.0.0.1`에서만 열고, 페이지를 열 때 넣은 일회용 토큰이 있는 요청만 받습니다. 바꾸는 요청은 경로를 받지 않고 후보 id만 받아 서버가 다시 검사한 뒤 맞춰 봅니다.

## 목차 알림 훅

지금 탭의 **켜기**를 누르면 `~/.claude/settings.json`의 `hooks.Stop`에 훅이 들어갑니다. 대화가 끝날 때마다 그 프로젝트의 `MEMORY.md`를 재고, 4,000바이트나 150자 줄 기준을 넘는 상태가 바뀔 때만 한 줄로 알립니다. 다른 훅은 건드리지 않고, 기록 탭에서 되돌리거나 **끄기**로 뺍니다. 훅은 오류가 나도 Claude Code를 멈추지 않습니다.
