📝 새록 지원서 경험 장부로 쓰는 자기소개서
화면을 준비하는 중입니다…

1경험 장부

자기소개서의 사실 문장은 모두 이 장부의 경험 ID(E01, E02…)를 근거로 씁니다. 행동에는 [한 일]·[설계안(도입 가정)]·[계획]을 붙이고, Claude가 정리한 칸의 '(AI 정리, 확인 전)'은 직접 확인한 뒤 지웁니다. 전화번호·이메일·주민번호는 넣지 않습니다.

표기 규칙(style.md, 선택)

쓰지 않을 말·바꿀 말·문장 길이·말투를 적으면 검사가 지켰는지 봅니다.

2채용 공고

공고 본문을 그대로 붙여 넣습니다. 브라우저는 다른 사이트 주소를 읽지 못하므로 URL은 출처로만 적습니다. 캡처 이미지만 있으면 Claude가 글을 옮겨 적고, 직접 대조해 '확인함'을 누르기 전에는 분석하지 않습니다.

상태: 확인함

요구·우대 역량을 장부 경험과 잇고, 17번 새록 사전에 있는 용어만 뜻을 붙입니다.

3공고 분석 숨은 키워드는 AI 해석

웹 화면에서는 회사 조사를 하지 않습니다. '회사 조사' 칸은 '조사 안 됨'으로 두고, 조사가 필요하면 Claude Code에서 /saerok-apply:analyze로 출처·확인 날짜와 함께 채웁니다.

    4문항 초안

    문항을 넣으면 Claude가 장부에서 경험 후보를 골라 한 문항씩 씁니다. 장부에 근거가 없으면 지어내지 않고 [사용자 확인 필요: …]를 남깁니다. 초안은 늘 직접 고친 뒤 확정합니다.

    첨삭 모드 (내가 쓴 글을 고치기)

    원문은 그대로 두고 새 초안 파일로 고칩니다. 원문에 없던 사실은 장부 근거가 있을 때만 더합니다.

    5초안 새 초안

    저장할 때마다 draft-날짜.md 새 파일로 남기고, 이전 판은 덮어쓰지 않습니다.

    6자기소개서 검사

    AI 없이 규칙으로 봅니다. 같은 글이면 늘 같은 결과입니다(내 PC의 saerok-apply check와 같음). 불러온 판에서 '상태: 확정'이던 문항이 바뀌면 오류로 알립니다.

    7제출본 넘기기

    오류가 없고 모든 문항이 확정이면 근거 주석을 뺀 제출본을 만듭니다. 내 PC 모드는 19번 새록 면접관의 서류 폴더에 넘기고(같은 이름이 있으면 날짜를 붙여 새로 저장), 브라우저 모드는 파일로 내려받습니다.
