# 새록 심사단: 기록 비교

사용자 입력: $ARGUMENTS

명령은 이 스킬 폴더 두 단계 위의 `bin/saerok-idea`입니다. 답은 존댓말 한국어로 씁니다.

1. 입력이 없으면 기록 폴더(`saerok-idea home`)의 아이디어 폴더 목록을 보여 주고 하나를 고르게 합니다.
2. 비교합니다.

```bash
saerok-idea compare "<아이디어 폴더 또는 verdict.md>"
```

3. 표를 그대로 보여 주고, 바뀐 것만 짧게 짚습니다: 판정이 바뀐 기록, 결과가 바뀐 가정(예: 반박 → 받침), 다른 방향에서 온 기록(`from`).
4. 점수가 올랐다고 아이디어가 좋아졌다고 말하지 않습니다. 심사위원은 AI 시뮬레이션이고, 가정 검증 결과가 바뀐 근거 링크를 함께 봐야 한다고 알립니다.
