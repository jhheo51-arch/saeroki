1아이디어 입력

한 줄은 꼭 필요합니다. 4칸은 비워 두면 미정으로 심사합니다. 무엇을·누구에게가 미정이면 판정은 판단 보류(정보 부족)가 됩니다.

분석은 Claude(Anthropic)가 하고, 확인한 검색어는 검색 서비스로 나갑니다. 아이디어 원문은 검색어에 넣지 않지만 완전한 비공개는 아닙니다.

한 줄에 적힌 것만 옮기고, 없는 칸은 비워 둡니다.
손익분기·패널·아는 경쟁 서비스 (선택)

손익분기는 내가 넣은 값으로만 계산합니다. AI가 가격을 짐작해 넣지 않습니다.

심사위원 3명이 먼저 평가하고, 웹 검색 전에 검색어를 확인받습니다.

2심사위원 3명 AI 시뮬레이션

기준표대로 1~5점과 투표를 냅니다. 투표는 판정 규칙에 쓰입니다.

    3검색어 확인

    가정마다 반박 쪽 검색어를 먼저 씁니다. 체크한 검색어만 그대로 검색 서비스로 나갑니다. 아이디어를 짐작할 수 있는 낱말은 고치거나 빼 주세요.

      4가정 검증·경쟁 조사·패널

      검색 결과에 실제로 나온 링크만 근거로 남깁니다. 근거가 없으면 지어내지 않고 확인 못 함으로 둡니다.
