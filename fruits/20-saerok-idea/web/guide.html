SAEROKI · 20번 열매
아이디어 검증

새록 심사단 설치하고 쓰는 법

아이디어 한 줄을 넣으면 만들기 전에 진행·조건부·보류 판정과 다듬은 방향 2~3개를 받습니다.

심사위원 3명이 점수와 표를 내고, 아이디어가 기대는 가정 3개를 공개 근거로 직접 확인합니다. 판정은 AI가 아니라 고정된 규칙의 스크립트가 정하므로 같은 표와 같은 근거면 언제나 같은 판정이 나옵니다. 기획서는 쓰지 않고 4번 새록 검토관에 넘깁니다.

준비물

  • Claude Code(Claude Pro 이상 요금제)에 로그인한 PC. 웹 화면만 쓸 때는 내 Claude API 키
  • Python 3.10 이상. 명령 프롬프트에서 python --version으로 확인
  • 아이디어 한 줄. 무엇을·누구에게·어떻게 돈을 버는지·왜 지금 중 아는 것만 있어도 됩니다
  • 가격·비용을 안다면 그 숫자(손익분기 계산용, 없으면 계산하지 않음)

사용 방법

1

플러그인 설치

Claude Code 대화창에 설치 두 줄을 넣습니다. 처음 한 번만 하면 됩니다.

/saerok-idea:judge가 명령 목록에 보이면 성공

2

아이디어 한 줄로 심사 시작

/saerok-idea:judge 뒤에 아이디어를 적습니다. 4칸 중 빠진 것만 최대 3문항 묻고, 모르면 미정으로 두고 진행합니다.

3

검색어와 사용량 확인

가정 검증·경쟁 조사에 보낼 웹 검색어(아이디어 원문이 아닌 일반 낱말)와 패널 규모, 예상 사용량을 먼저 보여 줍니다. 빼거나 바꿀 검색어를 말한 뒤 확인하면 시작합니다.

아는 경쟁 서비스가 있으면 이때 함께 알려 주세요

4

판정과 방향 받기

심사위원 점수, 가정마다 받침·반박·확인 못 함과 링크·확인 날짜, 경쟁 서비스 표, 가상 패널의 반대 이유, 손익분기, 다듬은 방향 2~3개(추천 하나)가 verdict.md로 저장됩니다.

판정 바로 아래 아이디어가 이렇게 바뀌었어요에서 추천 방향이 내 아이디어의 어느 칸을 왜 바꾸는지 바뀐 칸만 표로 볼 수 있습니다. 방향을 골라 다시 심사하면 이전 입력에서 무엇이 바뀌었는지도 함께 남습니다.

기록은 내 PC ~/.saerok/idea/<아이디어>/<날짜>/에만 남습니다

5

방향을 골라 다시 심사하거나 기획으로 넘기기

마음에 드는 방향 번호로 다시 심사하면 같은 아이디어 폴더에 새 기록이 쌓여 전후를 비교할 수 있습니다. 진행·조건부면 4번 새록 검토관의 설계 스무고개를 이 판정에서 시작합니다.

판정은 이렇게 정합니다

진행진행 2표 이상, 보류 0표, 반박된 가정 없음
조건부그 밖의 표, 또는 진행인데 다른 가정이 반박됨
보류보류 2표 이상, 또는 '문제가 있다' 가정이 반박됨
판단 보류무엇을·누구에게가 미정이거나 가정 3개 모두 확인 못 함

가상 사용자 패널과 손익분기는 판정에 쓰지 않습니다. 패널은 AI 시뮬레이션이라 반대 이유 모음으로만 보여 줍니다.

복사해서 쓰기

설치 두 줄

/plugin marketplace add jhheo51-arch/saeroki
/plugin install saerok-idea@saeroki

심사 시작(가상 예시)

/saerok-idea:judge 동네 1인 카페 사장님에게 원두·우유 재고가 떨어지기 전에 알려 주는 서비스

패널을 100명으로

/saerok-idea:judge 동네 1인 카페 사장님에게 원두·우유 재고가 떨어지기 전에 알려 주는 서비스 --full

고른 방향 다시 심사

/saerok-idea:judge --from "<verdict.md 경로>" --direction 2

한 단계만 다시

/saerok-idea:judge --step assumptions "<기록 폴더>"

기록 비교

/saerok-idea:compare "<아이디어 폴더>"

기획으로 넘기기

/saerok-prd:design --from "<verdict.md 경로>"

손익분기만 계산(터미널)

bin/saerok-idea breakeven --price 9900 --unit-cost 1500 --fixed-cost 300000

다른 화면으로 쓰기

어디서여는 법키·기록
웹심사 화면내 API 키를 넣으면 브라우저가 Anthropic에 바로 연결. 기록은 그 브라우저에만, verdict.md로 내려받기
터미널saerok-idea같은 화면이 내 PC에서 열리고 Claude Code 구독으로 돌아감. 기록은 ~/.saerok/idea/

막힐 때

"기록 폴더가 git 저장소 안입니다"라며 멈춰요

아이디어가 실수로 공개되지 않도록 저장소 안에는 저장하지 않습니다. 기본 위치 ~/.saerok/idea/를 쓰거나 SAEROK_IDEA_HOME을 저장소 밖 폴더로 바꿔 주세요.

판정이 '판단 보류(정보 부족)'로 나와요

무엇을·누구에게 칸이 미정이거나 가정 3개를 모두 확인하지 못한 경우입니다. 칸을 채우거나 검색어를 바꿔 다시 심사하세요.

손익분기가 계산되지 않아요

가격·고객당 비용·고정비는 내가 준 값이나 링크가 있는 값만 씁니다. 결과에 적힌 '필요한 값'을 알려 주면 계산합니다.

터미널 화면이 Claude에 연결되지 않아요

Claude Code가 설치·로그인되어 있는지 확인하세요. 없으면 화면 설정에서 API 키 방식으로 바꾸거나 saerok-idea --api로 엽니다.

주의할 점

  • 판정은 만들기 전에 걸러 보는 참고입니다. 투자·창업의 최종 판단을 대신하지 않습니다.
  • 심사위원과 가상 패널은 AI 시뮬레이션입니다. 패널 비율을 실제 수요나 구매 비율로 읽지 마세요.
  • 근거가 없는 시장 규모·경쟁사 수치는 쓰지 않고 확인 못 함으로 둡니다.
  • 실제 인터뷰나 작은 판매 시험처럼 웹으로 확인할 수 없는 일은 '직접 확인할 일'로 남깁니다.

파일은 내 PC에만 저장되지만, 분석은 Claude(Anthropic 서버)가 하고 검색어는 검색 서비스로 나갑니다. 완전한 비공개는 아니니 민감한 아이디어는 일반 낱말로 바꿔 넣어 주세요. 공용 PC의 웹 화면에는 API 키를 넣지 마세요.
