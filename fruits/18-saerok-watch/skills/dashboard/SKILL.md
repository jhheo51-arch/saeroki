# 새록 파수꾼 대시보드

이 스킬 폴더의 두 단계 위가 플러그인 폴더이고, 실행 스크립트는 `<플러그인 폴더>/hooks/sentry`입니다.

1. 사용자가 대시보드를 원하면 아래 명령을 **백그라운드**로 실행하고, `http://127.0.0.1:8718`을 열었다고 알립니다. 서버는 사용자가 끝낼 때까지 켜 둡니다.

   ```bash
   bash "<플러그인 폴더>/hooks/sentry" serve
   ```

2. 요약만 원하면 `bash "<플러그인 폴더>/hooks/sentry" status`를 실행해 결과를 한국어로 짧게 정리합니다.
3. 대시보드 적용 탭의 설정 변경은 사용자가 직접 누르게 둡니다. 사용자가 요청하지 않은 설정은 바꾸지 않습니다.
4. Python 3.10 이상이 없다는 오류가 나면 설치 주소를 알려 줍니다.
