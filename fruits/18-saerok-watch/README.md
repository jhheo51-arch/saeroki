# 🌸 18 새록 파수꾼

내 PC의 Claude Code 사용 기록을 지켜보다가 대화가 너무 커지면 그 자리에서 한 줄로 알려 주고, 어디서 토큰이 새는지와 줄이는 방법을 대시보드로 보여 주는 감시 에이전트입니다. 설정은 내가 적용 탭에서 고른 것만, 백업한 뒤 바꾸고 되돌릴 수 있습니다.

- 설계: [PRD v1.9](../../docs/PRD-v1.9.md)
- 공통 원칙: [AGENT-SPEC.md](../../AGENT-SPEC.md)
- 외부 라이브러리 없이 Python 표준 라이브러리만 씁니다.

```text
🪖 파수꾼 새록이 · 주의: 컨텍스트 20.5만 토큰. 작업이 바뀌면 새 세션에서 이어 가면 사용량을 아낄 수 있어요.
```

## 왜 필요한가

Claude Code는 응답마다 지금까지의 대화 전체를 다시 읽습니다. 2026-10-16 오전 측정 시점에 이 PC의 기록(세션 29개, 응답 6,605번)을 세어 보니 처리량의 82%가 컨텍스트 30만 토큰을 넘은 응답에서 나왔습니다. 세션을 언제 끊을지만 잘 정해도 사용량이 크게 줄어듭니다.

## 설치와 실행

### 어느 컴퓨터든: Claude Code 플러그인(추천)

터미널에서 아래 한 줄, 또는 Claude Code 대화창에서 `/plugin marketplace add jhheo51-arch/saeroki` 뒤 `/plugin install saerok-watch@saeroki`면 됩니다. 훅이 자동으로 켜지고 대시보드는 `/saerok-watch:dashboard`로 엽니다. Python 3.10 이상이 필요합니다.

```bash
claude plugin install saerok-watch --marketplace jhheo51-arch/saeroki
```

플러그인으로 설치하면 적용 탭의 `파수꾼 훅 설치`는 이미 켜진 것으로 보고 나오지 않습니다.

### 이 저장소에서 직접

저장소 루트에서 한 번만 설치합니다.

```powershell
python -m pip install -e fruits/18-saerok-watch
```

```powershell
saerok-watch            # 대시보드 열기(http://127.0.0.1:8718)
saerok-watch status     # 터미널 요약
saerok-watch export     # 공개용 날짜별 집계(data/public-daily.json) 만들기
saerok-watch test-alert # Windows 알림 미리 보기
```

## 대시보드

| 탭 | 보여 주는 것 |
|---|---|
| 지금 | 전체 처리량, 30만 이상 응답의 몫, 세션 기본 부담, 최근 30분 안에 움직인 세션의 컨텍스트 게이지, 경고 이력 |
| 추이 | 날짜별 처리량(30만 이상 몫 표시), 크기 구간별 비율, 세션별 사용량, 세션을 누르면 응답별 컨텍스트 곡선과 급증 원인, 최근 14일 급증 원인 비율 |
| 제안 | 효과가 큰 순서의 절약 제안: 측정 · 추정 · 방법 · 잃는 것 · 할 일. 급증 원인 1위와 상태줄 켜기 포함 |
| 적용 | 버튼 하나로 적용, 경고 기준 바꾸기, 적용 이력과 되돌리기, 조치마다 전후 7일 효과 |

1분마다 저절로 새로 고칩니다.

## 실시간 경고

적용 탭의 **파수꾼 훅 설치**를 누르면 `~/.claude/settings.json`의 `hooks.Stop`에 훅이 들어갑니다. Claude가 응답을 끝낼 때마다 그 세션의 컨텍스트 크기를 재고, 주의(기본 20만)나 경고(기본 40만)를 처음 넘을 때 대화에 한 줄을 띄웁니다. 같은 순간 화면 오른쪽 아래에 K-2 소총을 든 파수꾼 새록이 그림이 들어간 Windows 알림도 뜹니다(지금 레벨의 새록이 모습을 따라 자람). 알림은 적용 탭의 경고 기준에서 끄거나 `알림 시험` 버튼으로 미리 볼 수 있습니다. 압축이나 `/clear`로 작아지면 다시 커질 때 또 알립니다. 훅은 오류가 나도 Claude Code를 멈추지 않습니다.

## 상태줄

적용 탭의 **파수꾼 상태줄 켜기**를 누르면 Claude Code 입력창 아래에 지금 세션의 컨텍스트 크기가 늘 보입니다.

```text
🪖 18.2만 █████░░░ 주의까지 1.8만
```

- 막대는 경고 기준을 꽉 찬 것으로 보고, 여유·주의·경고에 따라 초록·노랑·빨강으로 바뀝니다.
- 주의를 넘으면 `경고까지 …`, 경고를 넘으면 `경고 넘음 +… · 새 세션 권장`으로 바뀝니다.
- `settings.json`의 `statusLine`을 바꿉니다. 이미 다른 상태줄을 쓰고 있으면 파수꾼으로 바뀌므로 제안 카드에 그 사실을 적고, 되돌리기로 원래 상태줄을 복구합니다.
- 플러그인은 상태줄을 대신 켤 수 없어서(Claude Code 규칙) 플러그인으로 설치해도 이 버튼을 한 번 눌러야 합니다. 플러그인을 업데이트해 설치 폴더가 바뀌면 다시 눌러 주세요.
- 오류가 나면 `🪖 파수꾼 대기 중`만 보이고 Claude Code를 방해하지 않습니다.

## 급증 원인

응답 한 번에 컨텍스트가 2만 토큰 이상 커진 곳을 **급증**으로 잡고, 직전 응답 뒤에 들어온 것(파일 읽기, 명령 출력, 검색 결과, 서브에이전트 결과, 스킬 안내문, 웹 페이지, MCP 도구, 스크린샷, 사용자 붙여 넣기, Claude 응답, Claude Code가 끼워 넣는 도구·스킬 목록과 파일 변경 알림)으로 원인을 어림합니다. 글자 수를 3으로 나누고 이미지 1장은 1,300토큰으로 셉니다. 어림값 합이 실제 증가보다 크면 비율대로 줄이고, 모자라면 나머지를 `기록에 안 남은 부분(도구 정의 등)`으로 둡니다. 실제 기록에서는 이 몫이 절반 가까이 나오는데, 도구 정의처럼 기록 파일에 내용이 남지 않는 것이라 더 짚을 수 없습니다. 파일 이름만 남기고 경로와 원문은 저장하지 않습니다.

## 적용 탭에서 바꿀 수 있는 것

| 조치 | 바꾸는 곳 |
|---|---|
| 파수꾼 훅 설치 | `settings.json` › `hooks.Stop` |
| 파수꾼 상태줄 켜기 | `settings.json` › `statusLine` |
| 직접 넣은 훅 빼기(플러그인과 겹칠 때) | `settings.json` › `hooks.Stop`에서 파수꾼 훅만 |
| 자동 압축 창 200K로 | `settings.json` › `autoCompactWindow` |
| 안 쓰는 MCP 서버 끄기 | `~/.claude.json` › 프로젝트별 `disabledMcpServers` |
| 안 쓰는 플러그인 끄기 | `settings.json` › `enabledPlugins`(직접 설치한 플러그인만) |

claude.ai 계정에서 동기화된 플러그인과 프로젝트 `CLAUDE.md` 필독 문서는 제안만 하고 자동으로 바꾸지 않습니다.

- 적용 전 파일을 `~/.saerok-watch/backups/`에 복사합니다.
- 되돌리기는 바꾼 키만 이전 값으로 돌리고, 적용 뒤 다른 사람이 또 바꾼 키는 건드리지 않고 알려 줍니다.
- 대시보드는 `127.0.0.1`에서만 열리고, 페이지를 열 때 받은 일회용 토큰이 있어야 바꾸는 요청을 받습니다.
- 바뀐 설정은 새로 여는 Claude Code 세션부터 반영됩니다.

### 효과 확인

적용 이력의 조치마다 적용 전 7일과 적용 뒤 7일(되돌렸다면 되돌리기 전까지)에 **시작한** 세션을 비교합니다. 조치마다 대표 지표 하나로 `효과 있음`·`변화 없음`·`나빠짐`을 붙이고(5% 안쪽은 변화 없음), 양쪽 세션이 3개씩 모이고 적용 뒤 3일이 지나기 전에는 `측정 중`으로 둡니다. 아직 진행 중인 세션은 덜 자라 작게 나오므로 비교에서 뺍니다.

| 조치 | 대표 지표 |
|---|---|
| MCP 서버·플러그인 끄기 | 세션 기본 부담(첫 응답 크기) 평균 |
| 자동 압축 창 낮추기 | 30만 이상 응답의 처리량 몫 |
| 훅·상태줄 | 세션 최대 크기 평균(경고를 보고 일찍 새 세션으로 옮겼는지) |

같은 7일 안에 다른 조치를 했다면 효과가 섞였다고 알려 줍니다. 하는 일이 바뀐 영향도 섞이므로 참고용 비교입니다.

## 기록과 공개

| 위치 | 내용 |
|---|---|
| `~/.saerok-watch/` | 분석 캐시(세션 첫 문장 60자와 폴더 이름 포함), 경고 이력, 적용 이력, 백업. 내 PC에만 있습니다 |
| [`data/public-daily.json`](data) | 날짜별 처리량·응답 수·세션 수·최대 컨텍스트·30만 이상 비율·스크린샷 수. 제목·원문·경로·세션 ID는 없습니다 |

공개 집계는 `saerok-watch export`로 만든 뒤 내용을 확인하고 직접 커밋합니다. `export`는 이 저장소에서 설치(`pip install -e`)했을 때만 저장소 안 `data/`에 쓰므로, 플러그인 설치본에서는 `--out 파일경로`로 위치를 정해 주세요.

## 측정 방법과 한계

- 응답 하나의 컨텍스트 = 새 입력 + 캐시 읽기 + 캐시 쓰기 토큰. 한 응답이 기록에 여러 줄로 나뉘어 저장되므로 메시지 ID로 한 번만 셉니다.
- 요금제 한도(5시간·주간 %)가 캐시 읽기를 얼마나 무겁게 세는지는 확인하지 못했습니다. 처리량은 "어디가 큰지"를 비교하는 숫자입니다.
- "20만에서 압축하면 지금의 약 35%"는 크기 구간 대표값으로 어림한 단순 모형이며 압축 요약을 만드는 비용은 빠져 있습니다.
