모의 면접

새록 면접관 5명에게 모의 면접 보는 법

자기소개서와 채용 공고를 넣으면 면접관 5명이 동시에 심사하고, 근거 줄이 달린 질문 10개와 verdict.md를 줍니다.

압박·인사·실무·임원·숫자 검증 면접관이 각자 4항목 고정 기준표로 점수를 냅니다. 질문마다 내 글의 몇째 줄을 보고 물었는지 달고, 그 문장이 정말 거기 있는지 프로그램이 확인합니다. 실전 연습 점수는 회차마다 쌓여 전후 비교와 실제 면접 적중률까지 봅니다. 합격 가능성은 예측하지 않습니다.

준비물

  • 웹 화면만 쓸 때: 내 Claude API 키. 설치할 것이 없습니다
  • 내 PC에서 쓸 때: Claude Code(Claude Pro 이상 요금제)에 로그인한 PC와 Python 3.10 이상(python --version으로 확인)
  • 자기소개서. 한글·워드·PDF라면 본문만 복사해 두세요
  • 채용 공고 본문(선택). 넣으면 '공고 요건 연결'·'회사 이해'까지 심사합니다

사용 방법

1

플러그인 설치

Claude Code 대화창에 아래 '설치 두 줄'을 넣습니다. 면접관 파일을 직접 만들 필요가 없습니다. 설치 뒤에는 새 대화창을 엽니다.

/saerok-interview:panel이 명령 목록에 보이면 성공

2

서류 폴더 만들기

대화창에 /saerok-interview:panel만 입력하면, 처음에는 심사 대신 내 PC에 서류 폴더와 양식 두 개를 만들어 줍니다. 이 폴더는 공개 저장소 밖에 있어 자기소개서가 올라갈 일이 없습니다.

Windows는 Win + R → %USERPROFILE%\.saerok\interview\서류로 바로 열기

3

자기소개서와 공고 넣기

양식을 메모장으로 열어 자기소개서.md는 내 글로, 공고-회사이름.md는 이름을 바꾸고(예: 공고-골목장터.md) 공고 본문으로 채웁니다. 문장 하나를 한 줄에 쓰면 근거 표시가 정확해집니다.

양식의 [새록 면접관 양식] 안내 줄을 지워야 시작합니다

4

면접 시작

어느 폴더에서든 /saerok-interview:panel --company 골목장터 한 줄, 또는 "골목장터 면접 보자"라고 말합니다. 개인정보 꼴(주민번호·전화번호·이메일)이 있으면 가린 값을 보여 주고 진행할지 먼저 묻습니다.

1~3분 뒤 판정표와 verdict.md 위치를 알려 줍니다

5

실전 연습과 비교

/saerok-interview:practice로 점수가 낮은 면접관 질문부터 하나씩 답합니다. 꼬리 질문 1~2번 뒤 채점하고 practice.md에 남깁니다. 자기소개서를 고쳐 다시 심사하면 /saerok-interview:compare로 회차별 변화를 봅니다.

기록은 내 PC ~/.saerok/interview/<날짜-회사>/에만 남습니다

면접관 5명과 기준표

면접관마다 4항목 10점입니다. 볼 수 없는 항목은 0점이 아니라 '해당 없음'으로 빼고 10점으로 환산합니다.

면접관3점 항목2점 항목
압박근거·수치, 본인 역할앞뒤 일관성, 침착함(답변에서만)
인사지원 동기, 협업조직 적합, 장기 근속
실무상황 판단, 실행 순서직무 용어, 공고 요건 연결
임원회사 이해, 왜 이 회사장기 포부, 핵심 요약(답변에서만)
숫자 검증수치의 출처, 계산 과정지표 정의, 비교 기준
합격권7점 이상
보류5점 이상
부족5점 미만

서류 단계의 판정이며 실제 합격 예측이 아닙니다. 근거 원문을 내 글에서 찾지 못한 질문은 '확인 안 됨, 일반 질문'으로 표시됩니다.

복사해서 쓰기

설치 두 줄

/plugin marketplace add jhheo51-arch/saeroki
/plugin install saerok-interview@saeroki

서류 심사(가상 회사)

/saerok-interview:panel --company 골목장터

산업·직무 용어까지 넣어 심사

/saerok-interview:panel --company 골목장터 --industry platform --role pm

실전 연습(강도: 순한맛·보통·매운맛)

/saerok-interview:practice --level 보통

특정 면접관만 연습

/saerok-interview:practice --who pressure,numbers

회차별 점수 비교

/saerok-interview:compare --last 3

실제 면접 질문 기록

/saerok-interview:compare --real "<세션 폴더>"

자기소개서 양식(한 줄에 한 문장)

# 자기소개서

## 지원 동기

저는 ○○ 서비스에서 2년 동안 운영 PM으로 일했습니다.
그 경험으로 더 많은 판매자를 돕는 플랫폼에서 일하고 싶어 지원했습니다.

## 가장 큰 성과

주문 화면 단계를 줄여 전환율을 30% 올렸습니다.
고객 문의를 직접 분류해 개선 순서를 정했습니다.

다른 화면으로 쓰기

어디서여는 법키·기록
웹면접 화면내 API 키를 넣으면 브라우저가 Anthropic에 바로 연결. 기록은 그 브라우저에만, verdict.md·practice.md로 내려받기
터미널saerok-interview같은 화면이 내 PC에서 열리고 Claude Code 구독으로 돌아감. 서류 폴더에서 불러오기 가능. 기록은 ~/.saerok/interview/
Claude Code/saerok-interview:panel위 사용 방법 그대로

화면은 새 면접·실전 연습·기록·비교 탭 세 개입니다. 실제 면접 질문은 한 줄에 하나씩 적고, 모의 질문과 비슷했던 줄 끝에 / Q3처럼 번호를 붙이면 적중으로 셉니다.

막힐 때

/saerok-interview:panel이 안 보여요

설치 뒤 새 대화창을 열어야 보입니다. /plugin에서 saerok-interview가 켜져 있는지 확인하세요.

"아직 양식 그대로입니다"라고 해요

양식의 >로 시작하는 안내 줄을 지우고 저장하세요.

한글 파일이나 공고를 읽지 않아요

.md·.txt만 읽습니다. 본문을 메모장에 붙여 넣어 저장하고, 공고는 공고-회사이름.md처럼 공고로 시작하게 이름을 붙이세요.

"면접 폴더가 git 저장소 안입니다"라며 멈춰요

자기소개서가 실수로 공개되지 않도록 저장소 안에는 만들지 않습니다. 기본 위치를 쓰거나 SAEROK_INTERVIEW_HOME을 저장소 밖 폴더로 바꿔 주세요.

점수가 너무 짜요

면접관은 일부러 깐깐합니다. 점수보다 '왜 그 질문을 했는지'와 고칠 점을 보세요.

터미널 화면이 Claude에 연결되지 않아요

Claude Code가 설치·로그인되어 있는지 확인하세요. 없으면 화면의 '키·설정'에서 API 키 방식으로 바꾸거나 saerok-interview --api로 엽니다.

주의할 점

  • AI 면접관은 연습용입니다. 실제 회사 면접 방식과 다를 수 있고, 합격 가능성을 예측하지 않습니다.
  • 서류 심사는 면접관 5명이 같은 글을 각자 읽어 평소 대화보다 사용량이 많이 듭니다. 아끼려면 --who로 면접관을 줄이세요.
  • 모범 답안 전문은 요청할 때만 줍니다. 기본은 '더 좋은 답의 방향' 한 줄입니다.

파일은 내 PC(웹 화면은 그 브라우저)에만 저장되지만, 심사는 Claude(Anthropic 서버)가 하므로 내용이 분석을 위해 전송됩니다. 주민번호·연락처는 지우고 넣으세요. 공용 PC의 웹 화면에는 API 키를 넣지 마세요.
