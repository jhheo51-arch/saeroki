1서류 넣기

자기소개서는 꼭 필요합니다. 채용 공고·이력서·포트폴리오는 있으면 넣습니다. 한 줄에 한 문장씩 쓰면 면접관이 질문마다 몇째 줄을 보고 물었는지 달아 줍니다.

서류 본문은 심사를 위해 Claude(Anthropic)로 보냅니다. 전화번호·이메일·주민번호는 지우고 넣어 주세요. 시작 전에 이런 꼴이 있는지 한 번 더 확인합니다.

산업·직무를 고르면 실무·숫자 검증 면접관이 그 분야 핵심 용어(17번 새록 사전)를 함께 봅니다. 둘 다 고르거나 둘 다 비워 두세요.

이력서·포트폴리오 (선택)
면접관 5명이 동시에 심사합니다(Claude 호출 5번).

2면접관 5명 AI 시뮬레이션

고정 기준표로 10점 환산 점수를 내고, 근거 원문이 달린 질문을 2개씩 만듭니다. 근거는 입력한 서류에 그 문장이 실제로 있는지 규칙으로 확인합니다.

    실전 연습

    서류 심사로 만든 질문을 서류 점수가 낮은 면접관부터 하나씩 묻습니다. 답하면 꼬리 질문 뒤 기준표로 채점합니다.

      면접 기록

      세션 이름(날짜) 순으로 답변 점수 변화, 반복해서 낮은 항목, 실제 면접 적중률을 봅니다.

      🔑 키·설정

      Claude API 키는 이 브라우저에만 저장되고, Anthropic(api.anthropic.com)으로만 보냅니다. 중간 서버는 없습니다. 심사·연습할 때마다 내 API 사용량이 듭니다.

      Claude 부르는 방식

      키는 Windows 자격 증명 관리자에 두고, 내 PC 서버가 Anthropic에 보낼 때만 붙입니다. 브라우저로는 보내지 않습니다.
