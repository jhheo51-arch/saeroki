# 새록 면접관 사용 안내

설치부터 자기소개서 준비, 대화창·터미널에서 올리는 방법, 결과 확인까지 순서대로 적었습니다. 설치는 [README 빠른 시작](README.md#빠른-시작)을 보세요.

## 1. 파일 준비

### 형식

- `.md` 또는 `.txt` 파일만 읽습니다. 글자 인코딩은 UTF-8(Windows 메모장 기본값)입니다.
- 한글(.hwp)·워드(.docx)·PDF는 바로 읽지 않습니다. 본문을 전체 선택해 복사하고 메모장에 붙여 넣은 뒤 `자기소개서.txt`로 저장하세요.

### 쓰는 법

면접관은 질문마다 "몇째 줄의 어느 문장을 보고 물었는지"를 달고, 그 문장이 정말 그 줄(앞뒤 한 줄 포함)에 있는지 확인합니다. 그래서 줄을 나누는 방식이 근거 표시의 정확도를 좌우합니다.

| 규칙 | 이유 |
|---|---|
| 문장 하나를 한 줄에 씁니다 | 문단 전체가 한 줄이면 근거가 어느 문장인지 흐려집니다 |
| 문항은 `##` 제목으로 나눕니다 | 면접관이 문항별로 읽고, 판정에서도 찾기 쉽습니다 |
| 수치는 원래 쓴 그대로 둡니다 | 숫자 검증 면접관이 출처·계산을 묻는 재료입니다 |
| 전화번호·이메일·주민번호는 지웁니다 | 시작할 때 자동으로 찾아 묻지만, 처음부터 없는 편이 안전합니다 |

```markdown
# 자기소개서

## 지원 동기

저는 ○○ 서비스에서 2년 동안 운영 PM으로 일했습니다.
그 경험으로 더 많은 판매자를 돕는 플랫폼에서 일하고 싶어 지원했습니다.

## 가장 큰 성과

주문 화면 단계를 줄여 전환율을 30% 올렸습니다.
고객 문의를 직접 분류해 개선 순서를 정했습니다.
```

가상 예시 전체는 [`examples/resume-letter.md`](examples/resume-letter.md), 공고 예시는 [`examples/posting.md`](examples/posting.md)에 있습니다.

### 함께 넣을 수 있는 파일

| 파일 | 옵션 | 없으면 |
|---|---|---|
| 자기소개서 | (필수, 첫 번째 값) | 시작하지 않고 경로를 묻습니다 |
| 채용 공고 | `--posting` | 실무 '공고 요건 연결', 임원 '회사 이해'가 해당 없음 |
| 이력서 | `--resume` | 자기소개서만으로 심사 |
| 포트폴리오 | `--portfolio` | 자기소개서만으로 심사 |

모두 같은 규칙(`.md`·`.txt`, 한 줄에 한 문장)으로 준비합니다. 공고는 회사 사이트의 본문을 그대로 붙여 넣으면 됩니다.

## 2. 저장 위치

원본은 **새록이 저장소 밖** 아무 폴더에 둡니다. 저장소는 공개라서, 안에 두면 실수로 커밋할 수 있습니다.

```text
C:\Users\<사용자>\Documents\면접\       ← 원본(내가 고치는 파일)
├─ 자기소개서.md
├─ 공고-골목장터.md
└─ 이력서.md
```

심사를 시작하면 사본이 면접 폴더로 복사되고, 이후 기록은 모두 그쪽에 쌓입니다. 원본은 바뀌지 않으므로, 자기소개서를 고친 뒤 다시 심사하면 회차가 새로 생겨 전후 비교가 됩니다.

```text
C:\Users\<사용자>\saerok-interview\    ← 면접 폴더(자동)
└─ 2026-10-17-골목장터\
   ├─ inputs\        자기소개서.md · 채용 공고.md 사본
   ├─ session.json   회사·산업·직무, 원본 파일 지문(sha256)
   ├─ score.json     서류 점수·질문, 답변 점수, 실제 면접 질문
   ├─ 판정.md        판정표·질문 10개와 근거·고칠 점
   └─ practice.md    실전 연습 기록
```

- 면접 폴더 위치는 환경 변수 `SAEROK_INTERVIEW_HOME`으로 바꿀 수 있습니다. git 저장소 안을 가리키면 세션을 만들지 않고 멈춥니다.
- 같은 날 같은 회사로 다시 심사하면 `2026-10-17-골목장터-2`처럼 번호가 붙습니다.

## 3. 대화창에서 올리기

Claude Code 대화창(데스크톱 앱 Code 탭이나 터미널의 `claude`)에서 명령 뒤에 파일 경로를 적습니다. 파일을 대화창에 붙여 넣는 것이 아니라 **경로를 알려 주는 방식**입니다.

```text
/saerok-interview:panel "C:\Users\<사용자>\Documents\면접\자기소개서.md" --posting "C:\Users\<사용자>\Documents\면접\공고-골목장터.md" --company 골목장터
```

- 경로 얻기: 파일 탐색기에서 파일을 오른쪽 클릭하고 **경로로 복사**를 누르면 따옴표가 붙은 경로가 복사됩니다. 그대로 붙여 넣으세요.
- 경로에 띄어쓰기가 있으면 반드시 큰따옴표로 감쌉니다.
- 대화창을 연 폴더가 원본 폴더라면 `/saerok-interview:panel 자기소개서.md --posting 공고-골목장터.md`처럼 파일 이름만 써도 됩니다.
- 옵션 없이 `/saerok-interview:panel`만 입력하면 필요한 것을 차례로 묻습니다.
- 산업·직무를 주면 그 분야 핵심 용어로 질문합니다. 둘 다 주거나 둘 다 비웁니다.

  ```text
  /saerok-interview:panel 자기소개서.md --posting 공고.md --company 골목장터 --industry platform --role pm
  ```

  산업은 `ecommerce`·`platform`·`finance`, 직무는 `pm`·`data`·`marketing`·`cx`입니다.

## 4. 터미널에서 바로 시작

PowerShell이나 Git Bash에서 원본 폴더로 이동한 뒤 Claude Code를 면접 명령과 함께 띄웁니다.

```powershell
cd "$HOME\Documents\면접"
claude "/saerok-interview:panel 자기소개서.md --posting 공고-골목장터.md --company 골목장터"
```

- Claude Code 대화창이 열리면서 바로 심사를 시작합니다. 이어서 같은 창에서 실전 연습을 하면 됩니다.
- 플러그인을 설치하지 않았다면 저장소를 받아 한 번만 불러올 수 있습니다.

  ```bash
  git clone https://github.com/jhheo51-arch/saeroki.git
  claude --plugin-dir saeroki/fruits/19-saerok-interview "/saerok-interview:panel 자기소개서.md"
  ```

## 5. 심사 뒤 진행

| 하고 싶은 것 | 대화창 명령 |
|---|---|
| 질문 하나씩 실전 연습 | `/saerok-interview:practice` (가장 최근 세션을 고름) |
| 강도 바꾸기 | `/saerok-interview:practice --level 매운맛` (`순한맛`·`보통`·`매운맛`) |
| 특정 면접관만 | `/saerok-interview:practice --who pressure,numbers` |
| 회차별 점수 변화 | `/saerok-interview:compare --last 3` |
| 실제 면접 질문 기록 | `/saerok-interview:compare --real "<세션 폴더>"` |

- 실전 연습은 질문을 하나 던지고 답을 기다립니다. 대화창에 말하듯 답을 쓰면 꼬리 질문 1~2번 뒤 채점합니다.
- "그만", "오늘은 여기까지"라고 하면 멈추고, 다음에 같은 세션으로 이어 합니다.
- 모범 답안 전문은 요청할 때만 줍니다. 기본은 "더 좋은 답의 방향" 한 줄입니다.

## 6. 결과 보기

- `판정.md`: 면접관 5명의 점수(10점 환산)와 판정(7점 이상 합격권, 5점 이상 보류, 그 아래 부족), 질문 10개와 근거 원문, 고칠 점. 근거 원문을 입력 파일에서 찾지 못한 질문은 '확인 안 됨, 일반 질문'으로 표시됩니다.
- `practice.md`: 실전 연습의 질문·답·꼬리 질문·점수·빠진 것.
- 서류 단계 판정이며 실제 합격 예측이 아닙니다.

## 7. 자주 묻는 것

| 질문 | 답 |
|---|---|
| `/saerok-interview:panel`이 안 보여요 | 설치 뒤 새 대화창을 열어야 보입니다. `/plugin`에서 `saerok-interview`가 켜져 있는지 확인하세요 |
| 한글 파일을 넣었더니 거절해요 | `.md`·`.txt`만 읽습니다. 본문을 메모장에 붙여 넣어 저장하세요 |
| 개인정보가 있다고 멈췄어요 | 가린 값과 줄 번호를 보여 주고 진행할지 묻는 단계입니다. 원본에서 지우고 다시 하거나 그대로 진행을 고릅니다 |
| 내 자기소개서가 어디로 가나요 | 파일은 내 PC 면접 폴더에만 저장됩니다. 다만 심사 자체는 Claude(Anthropic 서버)가 하므로 내용이 분석을 위해 전송됩니다 |
| Python 오류가 나요 | Python 3.10 이상이 필요합니다. `python --version`으로 확인하세요 |
