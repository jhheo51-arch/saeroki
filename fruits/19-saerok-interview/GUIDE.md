# 새록 면접관 사용 안내

면접관 5명(압박·인사·실무·임원·숫자 검증)이 내 자기소개서와 채용 공고를 각자 고정된 기준으로 심사합니다. 질문마다 내 글의 몇째 줄을 보고 물었는지 달아 주고, 실전 연습 점수를 회차마다 쌓아 비교합니다.

한 장으로 훑어보려면 [사용 안내 화면](https://jhheo51-arch.github.io/saeroki/interview/guide.html)을 여세요. 이 문서는 파일 이름 규칙·결과 폴더까지 자세히 적은 판입니다.

처음 한 번만 설치하고, **서류 폴더**에 자기소개서와 공고를 넣은 뒤 `/saerok-interview:panel`을 입력하면 됩니다. 파일 경로는 몰라도 됩니다.

## 화면으로 쓰기

명령 대신 화면에서 서류를 붙여 넣고 버튼으로 진행할 수도 있습니다. 화면은 탭 세 개(새 면접·실전 연습·기록·비교)로 나뉩니다.

| 어디서 | 여는 법 | Claude 사용량 | 기록이 남는 곳 |
|---|---|---|---|
| 웹 | [면접 화면](https://jhheo51-arch.github.io/saeroki/interview/)을 열고 '키·설정'에 내 Claude API 키를 넣음 | 내 API 크레딧 | 그 브라우저에만. `verdict.md`·`practice.md`로 내려받기 |
| 터미널 | `pip install -e "fruits/19-saerok-interview[keyring]"` 뒤 `saerok-interview` | 기본은 Claude Code에 로그인한 내 구독. `saerok-interview --api`면 API 키 | 내 PC 면접 폴더(`~/.saerok/interview/`) |

- 웹 화면은 키를 Anthropic(api.anthropic.com)에만 보내고 중간 서버가 없습니다. 공용 PC에서는 키를 넣지 마세요.
- 터미널 화면은 127.0.0.1에서만 열리고, '내 PC 서류 폴더에서 불러오기'로 아래 서류 폴더의 파일을 바로 채웁니다. 키는 Windows 자격 증명 관리자에 두고 브라우저로 보내지 않습니다.
- 실제 면접 질문 기록란에 한 줄에 질문 하나씩 적고, 모의 질문과 같았던 줄은 끝에 `/ Q3`처럼 번호를 붙이면 적중으로 셉니다.

## 원본 방식과 달라진 점

[AI ANTENNA의 '클로드 면접관 3명' 방식](https://imyoung-man.github.io/AI-ANTENNA/aitip-interview/guide.html)을 바탕으로, 시작은 더 짧게 하고 결과는 다시 확인할 수 있게 바꿨습니다.

| | 원본 방식 | 새록 면접관 |
|---|---|---|
| 준비 | 면접관 파일 3개를 메모장에 붙여 `.claude/agents`에 저장 | 플러그인 설치 두 줄. 면접관 파일을 직접 만들지 않음 |
| 자기소개서 위치 | 바탕화면 `모의면접` 폴더를 직접 만듦 | 첫 실행 때 `서류` 폴더와 양식 파일을 만들어 줌 |
| 시작 | 폴더에서 `claude`를 켠 뒤 긴 문장을 붙여 넣음 | 어느 폴더에서든 `/saerok-interview:panel` 한 줄, 또는 "골목장터 면접 보자" |
| 면접관 | 압박·인사·실무 3명 | 3명에 임원·숫자 검증을 더해 5명 |
| 채용 공고 | 쓰지 않음 | 공고를 넣으면 '공고 요건 연결'·'회사 이해'까지 심사 |
| 점수 | 면접관마다 10점, 기준 없음 | 면접관마다 4항목 고정 기준. 볼 수 없는 항목은 0점이 아니라 '해당 없음' |
| 질문 근거 | 따옴표로 문장 인용 | 줄 번호까지 달고, 그 문장이 정말 내 글에 있는지 프로그램이 확인 |
| 실전 연습 | 답하면 채점하고 더 좋은 답 | 꼬리 질문 1~2번, 강도 3단계, 점수 낮은 면접관부터. 모범 답안 전문은 요청할 때만 |
| 기록 | `판정.md` 한 장 | 회차마다 세션 폴더. 점수 변화와 실제 면접 적중률 비교 |
| 개인정보 | 직접 지움 | 시작 전에 주민번호·전화번호·이메일 꼴을 찾아 묻기 |

## 준비물

- Claude Code(Claude Pro 이상 요금제). [claude.com/claude-code](https://claude.com/claude-code) 안내대로 설치하고 로그인합니다.
- Python 3.10 이상. 명령 프롬프트에서 `python --version`으로 확인합니다.
- 자기소개서와 채용 공고. 한글·워드·PDF라면 본문만 복사해 두세요.
- Windows·맥 모두 됩니다.

## 사용 방법

### 1. 플러그인 설치(처음 한 번)

Claude Code 대화창에 한 줄씩 입력합니다.

```text
/plugin marketplace add jhheo51-arch/saeroki
/plugin install saerok-interview@saeroki
```

설치 뒤에는 **새 대화창**을 열어야 `/saerok-interview:` 명령이 보입니다.

### 2. 서류 폴더 만들기(처음 한 번)

대화창에 그냥 입력합니다.

```text
/saerok-interview:panel
```

처음이면 심사 대신 서류 폴더와 양식 파일 두 개를 만들고 위치를 알려 줍니다.

| 컴퓨터 | 서류 폴더 |
|---|---|
| Windows | `C:\Users\<내 이름>\.saerok\interview\서류` |
| 맥 | `/Users/<내 이름>/.saerok/interview/서류` |

- Windows에서 바로 열기: `Win + R`을 누르고 `%USERPROFILE%\.saerok\interview\서류`를 입력한 뒤 Enter를 누릅니다.
- 맥에서 바로 열기: Finder에서 `Cmd + Shift + G`를 누르고 `~/.saerok/interview/서류`를 입력합니다.
- 이 폴더는 새록이 저장소 밖에 있습니다. 저장소가 공개라서, 자기소개서를 저장소 안에 두지 않도록 일부러 떼어 두었습니다.
- 위치를 바꾸려면 환경 변수 `SAEROK_INTERVIEW_HOME`을 다른 폴더로 정합니다. git 저장소 안을 가리키면 만들지 않고 멈춥니다.

### 3. 자기소개서와 공고 넣기

서류 폴더의 양식을 메모장(맥은 텍스트 편집기)으로 열어 채웁니다.

```text
.saerok\interview\서류\
├─ 자기소개서.md        ← 안내 줄을 지우고 내 자기소개서로 채움
└─ 공고-회사이름.md     ← '회사이름'을 바꾸고(예: 공고-골목장터.md) 공고 본문을 붙여 넣음
```

**파일 이름이 곧 종류입니다.** 프로그램은 파일 이름 앞부분으로 무엇인지 알아봅니다.

| 파일 이름 | 뜻 | 꼭 필요한가 |
|---|---|---|
| `자기소개서.md` (또는 `자소서.md`) | 자기소개서 | 필수 |
| `공고-골목장터.md` (또는 `채용공고-골목장터.md`) | 골목장터 채용 공고. `-` 뒤가 회사 이름 | 선택. 없으면 '공고 요건 연결'·'회사 이해'가 해당 없음 |
| `이력서.md` | 이력서 | 선택 |
| `포트폴리오.md` | 포트폴리오 요약 | 선택 |
| `자기소개서-골목장터.md` | 골목장터에만 쓰는 자기소개서 | 회사마다 다를 때만 |

- `.md`·`.txt`만 읽습니다. `.hwp`·`.docx`·`.pdf`는 알려만 주고 읽지 않으니, 본문을 복사해 같은 이름의 `.md`로 저장하세요. 메모장에서 저장할 때 파일 형식을 '모든 파일'로 바꾸고 이름 끝에 `.md`를 직접 붙입니다.
- 양식의 `[새록 면접관 양식]` 안내 줄이 남아 있으면 아직 안 채운 것으로 보고 시작하지 않습니다.
- 회사가 여러 곳이면 공고를 회사마다 하나씩 둡니다. 자기소개서는 공통 `자기소개서.md` 하나여도 되고, 특정 회사용 `자기소개서-회사이름.md`가 있으면 그쪽을 먼저 씁니다.

**쓰는 법.** 면접관은 질문마다 몇째 줄 문장을 보고 물었는지 달고, 그 문장이 정말 그 줄(앞뒤 한 줄 포함)에 있는지 확인합니다. 그래서 줄을 나누는 방식이 근거 표시의 정확도를 좌우합니다.

| 규칙 | 이유 |
|---|---|
| 문장 하나를 한 줄에 씁니다 | 문단 전체가 한 줄이면 근거가 어느 문장인지 흐려집니다 |
| 문항은 `##` 제목으로 나눕니다 | 면접관이 문항별로 읽고, 판정에서도 찾기 쉽습니다 |
| 수치는 원래 쓴 그대로 둡니다 | 숫자 검증 면접관이 출처·계산을 묻는 재료입니다 |
| 전화번호·이메일·주민번호는 지웁니다 | 시작할 때 자동으로 찾아 묻지만, 처음부터 없는 편이 안전합니다 |

```markdown
# 자기소개서

## 지원 동기

저는 ○○ 서비스에서 2년 동안 운영 PM으로 일했습니다.
그 경험으로 더 많은 판매자를 돕는 플랫폼에서 일하고 싶어 지원했습니다.

## 가장 큰 성과

주문 화면 단계를 줄여 전환율을 30% 올렸습니다.
고객 문의를 직접 분류해 개선 순서를 정했습니다.
```

공고는 회사 채용 페이지 본문을 그대로 붙여 넣으면 됩니다. 가상 예시 전체는 [`examples/resume-letter.md`](examples/resume-letter.md)와 [`examples/posting.md`](examples/posting.md)에 있습니다.

### 4. 면접 시작

세 방법 중 편한 것을 씁니다. 어느 폴더에서 Claude Code를 열었든 서류 폴더를 찾아갑니다.

**대화창에 명령 한 줄**

```text
/saerok-interview:panel
```

- 공고가 한 회사뿐이면 바로 시작합니다. 여러 회사면 어느 회사로 할지 묻습니다.
- 회사를 정해서 시작하려면 `/saerok-interview:panel --company 골목장터`라고 씁니다.
- 산업·직무를 주면 그 분야 핵심 용어로 질문합니다(둘 다 주거나 둘 다 비움). 산업은 `ecommerce`·`platform`·`finance`, 직무는 `pm`·`data`·`marketing`·`cx`입니다.

  ```text
  /saerok-interview:panel --company 골목장터 --industry platform --role pm
  ```

**대화창에 말로**

```text
골목장터 면접 보자
```

"자소서 심사해 줘", "면접 질문 뽑아 줘"도 같은 일을 합니다.

**터미널에서 바로**

```bash
claude "/saerok-interview:panel --company 골목장터"
```

Windows는 명령 프롬프트나 PowerShell, 맥은 터미널에서 입력합니다. Claude Code가 열리면서 바로 심사를 시작합니다.

시작하면 이렇게 진행됩니다.

1. 고른 파일과 회사를 보여 줍니다.
2. 개인정보 꼴이 있으면 가린 값과 줄 번호를 보여 주고 진행할지 묻습니다.
3. 면접관 5명이 동시에 심사합니다(1~3분).
4. `verdict.md` 위치와 판정표, 공통으로 나온 고칠 점을 알려 줍니다.

## 심사 뒤 진행

| 하고 싶은 것 | 대화창 명령 |
|---|---|
| 질문 하나씩 실전 연습 | `/saerok-interview:practice` (가장 최근 회차를 고름) |
| 강도 바꾸기 | `/saerok-interview:practice --level 매운맛` (`순한맛`·`보통`·`매운맛`) |
| 특정 면접관만 | `/saerok-interview:practice --who pressure,numbers` |
| 회차별 점수 변화 | `/saerok-interview:compare --last 3` |
| 실제 면접 질문 기록 | `/saerok-interview:compare --real "<세션 폴더>"` |

- 실전 연습은 질문을 하나 던지고 답을 기다립니다. 대화창에 말하듯 답을 쓰면 꼬리 질문 1~2번 뒤 채점합니다.
- "그만", "오늘은 여기까지"라고 하면 멈추고, 다음에 같은 회차로 이어 합니다.
- 모범 답안 전문은 요청할 때만 줍니다. 기본은 "더 좋은 답의 방향" 한 줄입니다.
- 자기소개서를 고친 뒤 `/saerok-interview:panel`을 다시 하면 회차가 새로 생겨 전후 비교가 됩니다.

## 결과 폴더

서류 폴더 옆에 회차마다 세션 폴더가 생깁니다. 심사할 때 서류를 복사해 두므로, 나중에 원본을 고쳐도 지난 회차의 근거 줄 번호는 그대로입니다.

```text
.saerok\interview\
├─ 서류\                  내가 고치는 원본
└─ 2026-10-17-골목장터\    회차 하나(같은 날 다시 하면 -2, -3)
   ├─ inputs\             그때 쓴 자기소개서·공고 사본
   ├─ session.json        회사·산업·직무, 사본 지문(sha256)
   ├─ score.json          서류 점수·질문, 답변 점수, 실제 면접 질문
   ├─ verdict.md          판정표·질문 10개와 근거·고칠 점
   └─ practice.md         실전 연습 기록
```

- `verdict.md`: 면접관 5명의 점수(10점 환산)와 판정(7점 이상 합격권, 5점 이상 보류, 그 아래 부족), 질문 10개와 근거 원문, 고칠 점. 근거 원문을 내 글에서 찾지 못한 질문은 '확인 안 됨, 일반 질문'으로 표시됩니다.
- `practice.md`: 실전 연습의 질문·답·꼬리 질문·점수·빠진 것.
- 서류 단계 판정이며 실제 합격 예측이 아닙니다.

## 서류 폴더 밖 파일을 쓸 때

다른 곳에 둔 파일은 경로를 직접 줍니다. 경로를 주면 서류 폴더보다 먼저 씁니다.

```text
/saerok-interview:panel "D:\취업\자기소개서.md" --posting "D:\취업\공고.md" --company 골목장터
```

- 파일 탐색기에서 파일을 오른쪽 클릭하고 **경로로 복사**를 누르면 큰따옴표가 붙은 경로가 복사됩니다.
- 경로에 띄어쓰기가 있으면 반드시 큰따옴표로 감쌉니다.
- 플러그인을 설치하지 않고 한 번만 써 보려면 저장소를 받아 그 실행에만 불러옵니다.

  ```bash
  git clone https://github.com/jhheo51-arch/saeroki.git
  claude --plugin-dir saeroki/fruits/19-saerok-interview "/saerok-interview:panel"
  ```

## 막힐 때

| 증상 | 해결 |
|---|---|
| `/saerok-interview:panel`이 안 보여요 | 설치 뒤 새 대화창을 열어야 보입니다. `/plugin`에서 `saerok-interview`가 켜져 있는지 확인하세요 |
| "아직 양식 그대로입니다"라고 해요 | 양식의 `>`로 시작하는 안내 줄(`[새록 면접관 양식]`이 든 줄)을 지우고 저장하세요 |
| 한글 파일을 넣었더니 읽지 않아요 | `.md`·`.txt`만 읽습니다. 본문을 메모장에 붙여 넣어 `자기소개서.md`로 저장하세요 |
| 공고가 무시돼요 | 파일 이름이 `공고-회사이름.md`처럼 `공고`로 시작하는지 보세요. 규칙 밖 이름은 무시했다고 알려 줍니다 |

## 주의할 점

- 파일은 내 PC에만 저장되지만, 심사 자체는 Claude(Anthropic 서버)가 하므로 내용이 분석을 위해 전송됩니다.
- API 키는 쓰지 않습니다. 대신 Claude 구독 사용량을 씁니다. 서류 심사는 면접관 5명(Sonnet)이 같은 글을 각자 읽어 평소 대화보다 많이 들고, 실전 연습은 지금 대화창 모델이 질문 수만큼 대화합니다. 아끼려면 실전 연습 전에 대화창 모델을 Sonnet으로 바꾸거나 `--who`로 면접관을 줄이세요.
- AI 면접관은 연습용입니다. 실제 회사 면접 방식과 다를 수 있고, 합격 가능성을 예측하지 않습니다.
