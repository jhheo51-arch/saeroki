# 새록 SQL 채점 결과

## 2026-10-16 · Claude Code 스킬 방식 · 20/20

| 항목 | 내용 |
|---|---|
| 방식 | Claude Code 스킬 `/saerok-sql` 지침대로 SQL 작성, `saerok-sql --run`으로만 실행 |
| 모델 | claude-opus-5-5 (Claude Code 하위 에이전트) |
| 결과 | 20문항 모두 통과, 모두 첫 시도에 실행 성공 |
| 답안 | [`answers-claude-code-2026-10-16.json`](answers-claude-code-2026-10-16.json) |
| 다시 채점 | `python eval/run_eval.py --answers eval/answers-claude-code-2026-10-16.json` |

진행 방법:
- 정답 SQL을 쓴 쪽과 푸는 쪽을 나눴습니다. 푸는 에이전트에는 정답을 뺀 질문 목록(`--export-questions`)만 주고, `eval` 폴더와 데이터 파일을 직접 열지 못하게 했습니다.
- 첫 채점은 19/20이었습니다. q12는 숫자가 정답과 같았지만, 답안이 비 온 날 구분을 참/거짓 대신 '비 온 날'·'비 안 온 날' 글자로 써서 채점기가 구분 컬럼의 짝을 찾지 못했습니다. 답안은 고치지 않고, q12는 평균 컬럼만 채점하도록(`check_columns`) 채점 기준을 고쳐 20/20이 되었습니다.

읽을 때 주의할 점:
- 정답 SQL도 Claude가 작성하고 실행해 확인한 초안입니다. 사람이 한 번 더 검토해야 확정 점수가 됩니다.
- 질문 20개는 모두 답이 하나로 정해지는 비교적 쉬운 질문입니다. 애매한 질문, 여러 표를 잇는 복잡한 질문, 답할 수 없는 질문은 아직 채점 세트에 없습니다.
- 사용자가 Claude Code에서 다른 모델을 쓰면 결과가 달라질 수 있습니다.
- Claude API를 직접 부르는 `saerok-sql` 터미널 방식(Sonnet 5.5)은 아직 채점하지 않았습니다.
