# 새록이 18번 열매 PRD v1.9: 새록 파수꾼

- 작성일: 2026-10-16
- 상태: 설계 확정, 구현 시작(🌸 꽃)
- 대상: 18번 열매(새로 추가), 이름 `새록 파수꾼`, 명령 `saerok-watch`
- 실행 환경: 내 PC의 Claude Code(훅)와 브라우저 대시보드(`127.0.0.1`에서만 열림)
- 이전 문서: [PRD v1.8](PRD-v1.8.md), 원래 목록은 [PRD v01](PRD-v01.md)

## 1. 한 문장 정의

새록 파수꾼은 내 PC의 Claude Code 사용 기록을 지켜보다가 대화가 너무 커지면 그 자리에서 한 줄로 알려 주고, 어디서 토큰이 새는지와 줄이는 방법을 대시보드로 보여 주며, 내가 고른 조치만 백업한 뒤 적용하고 되돌릴 수 있게 하는 감시 에이전트입니다.

## 2. 해결할 문제

Claude Code는 매 응답마다 지금까지의 대화 전체를 다시 읽습니다. 2026-10-16 이 PC의 기록 29개 세션(응답 6,605번)을 세어 보니 처리한 입력 26.8억 토큰 중 82%가 컨텍스트 30만 토큰을 넘은 응답에서 나왔고, 매 세션 기본으로 실리는 지침·도구·스킬 몫은 약 19%였습니다. 한 세션을 오래 끌수록 사용량이 빨리 닳는데, 작업 중에는 그 크기가 눈에 보이지 않습니다. 새록 파수꾼은 이 크기를 계속 지켜보고, 줄이는 결정은 사용자가 하게 돕습니다.

### 3-1. 어느 컴퓨터든 설치(2026-10-16)

사용자가 다른 컴퓨터에서도 바로 쓰기를 원해, 저장소를 Claude Code 플러그인 마켓플레이스(`.claude-plugin/marketplace.json`)로 만들고 18번 열매 폴더를 플러그인 `saerok-watch`로 묶었습니다. 터미널의 `claude plugin install saerok-watch --marketplace jhheo51-arch/saeroki` 한 줄(대화창에서는 `/plugin marketplace add jhheo51-arch/saeroki` 뒤 `/plugin install saerok-watch@saeroki`)로 설치하면 `Stop` 훅이 자동으로 켜지고, `/saerok-watch:dashboard`로 대시보드를 엽니다. GitHub README의 링크는 클릭만으로 프로그램을 실행할 수 없어서 복사해 붙여 넣는 한 줄로 정했습니다. 플러그인 설치본에는 `growth.py`가 없으므로 파수꾼 그림은 레벨 10 모습을 내장해 씁니다. 대시보드 색은 사용자 요청으로 주황·갈색 강조를 초록 계열로 바꿨습니다.

## 5. 경고 흐름

1. 사용자가 적용 탭에서 `파수꾼 훅 설치`를 누르면 `~/.claude/settings.json`의 `hooks.Stop`에 `PYTHONPATH=<열매 폴더> <python> -m saerok_watch hook` 명령이 추가됩니다. 플러그인으로 설치하면 대신 `hooks/sentry hook`이 자동 등록됩니다.
2. Claude가 응답을 끝낼 때마다 훅이 그 세션 기록의 마지막 `usage`를 읽습니다.
3. 주의(20만)나 경고(40만)를 처음 넘으면 대화에 한 줄을 띄우고, 파수꾼 새록이 그림이 든 Windows 알림을 보내고(대시보드에서 끌 수 있음), `~/.saerok-watch/alerts.jsonl`에 남깁니다.
4. 압축이나 `/clear`로 작아지면 단계를 내려, 다시 커질 때 또 알립니다.
5. 훅은 어떤 오류가 나도 Claude Code를 멈추지 않고 조용히 끝납니다.

## 6. 적용 탭

모든 적용은 바꾸기 전 파일을 `~/.saerok-watch/backups/`에 복사하고, 바꾼 키의 이전 값을 기록해 그 키만 되돌립니다. 대시보드는 `127.0.0.1`에서만 열리고, 페이지를 열 때 받은 일회용 토큰이 있어야 적용 요청을 받습니다.

| 조치 | 바꾸는 곳 | 자동 적용 |
|---|---|---|
| 파수꾼 훅 설치 | `settings.json`의 `hooks.Stop` | 예 |
| 자동 압축 창 낮추기 | `settings.json`의 `autoCompactWindow`(공식 설정) | 예 |
| 안 쓰는 MCP 서버 끄기 | `~/.claude.json` 프로젝트별 `disabledMcpServers`(공식 설정) | 예 |
| 안 쓰는 플러그인 끄기 | `settings.json`의 `enabledPlugins`(직접 설치한 플러그인만) | 예 |
| claude.ai 계정에서 동기화된 플러그인 | 끄는 방법을 확인하지 못함 | 아니요, 안내만 |
| 프로젝트 `CLAUDE.md` 필독 문서 줄이기 | 문서 내용 판단이 필요함 | 아니요, 크기와 후보만 보여 줌 |

## 7. 공개 집계

`fruits/18-saerok-watch/data/public-daily.json`에 날짜별로 처리량, 응답 수, 세션 수, 최대 컨텍스트, 30만 이상 비율, 스크린샷 수만 담습니다. 세션 제목, 대화 원문, 파일 경로, 세션 ID, 프로젝트 이름은 담지 않습니다.

## 8. 완료 기준

- 자동 검사: 중복 응답 한 번만 세기, 경고가 단계마다 한 번만 나오기, 적용 후 되돌리면 원래 값으로 돌아가기, 공개 집계에 경로·제목이 없기, 토큰 없는 적용 요청 거절.
- 실제 기록으로 대시보드 네 탭이 열리고 숫자가 이 문서 2절과 맞기.
- 훅을 설치한 뒤 실제 Claude Code 대화에서 경고 한 줄이 보이는지는 사용자 승인 후 확인.

## 9. 이번 단계에서 만들지 않는 것

- 자동 커밋·자동 적용
- 동기화 플러그인 끄기, `CLAUDE.md` 자동 수정
