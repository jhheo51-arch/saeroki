# 새록이 17번 열매 PRD v1.7: 새록 사전

- 작성일: 2026-10-15
- 상태: 첫 버전 구현 중(🌸 꽃). 용어집, 사전 웹 화면과 자동 검사를 만들었고 사용자 확인 전
- 대상: 17번 열매 `산업별 용어 정리 사전`, 이름 `새록 사전`
- 실행 환경: 1단계 저장소 안 HTML 웹 화면, 이후 Claude API로 AI 보충
- 이전 문서: [PRD v1.6](PRD-v1.6.md), 원래 목록은 [PRD v01](PRD-v01.md)

## 1. 한 문장 정의

새록 사전은 산업과 직무를 고르고 단어나 목적을 입력하면, 그 산업과 직무에서 자주 쓰는 용어를 사전처럼 출처와 함께 풀어 주는 온보딩용 용어 사전입니다.

## 2. 해결할 문제

새 회사나 새 팀에 들어가면 회의와 메신저에서 낯선 약어와 지표가 쏟아집니다. 일반 검색은 산업마다 다른 뜻을 섞어 보여 주고, 어디서부터 익혀야 할지 순서도 알려 주지 않습니다. 취업과 면접을 준비할 때도 지원하는 산업의 용어를 짧은 시간에 정리하기 어렵습니다.

## 3. 사용자와 상황

| 구분 | 상황 | 새록 사전이 하는 일 |
|---|---|---|
| 주 사용 | 입사 후 온보딩 | 회의에서 들은 단어를 바로 찾고, 입문 용어부터 하루 하나씩 익힙니다 |
| 보조 사용 | 취업·면접 준비 | 지원하는 산업과 직무의 실무·심화 용어를 묶음으로 정리합니다 |

## 4. 설정: 산업과 직무

사용자는 산업 하나와 직무 하나를 고릅니다. 둘 다 정해진 목록에서만 고르며, 목록은 데이터 파일에 두어 코드 수정 없이 나중에 늘릴 수 있게 합니다.

| 구분 | 첫 버전 목록 |
|---|---|
| 산업 | 이커머스·리테일, IT·플랫폼 서비스 |
| 직무 | 기획(PM·PO), 데이터 분석, 마케팅·그로스, CX·운영 |

나중에 추가할 산업 후보로는 금융·증권 등이 있으며, 추가할 때도 같은 형식의 용어집과 출처 검수를 거칩니다.

2026-10-15 금융·증권을 세 번째 산업으로 추가했습니다. 금융 전용 용어 46개(투자·상품, 규제·준법, 지표·리스크)를 공식 기관 출처로 만들고, 중요도 5인 공통 용어에도 금융·증권을 붙였습니다. 금융 전용 뜻에는 학습용 설명이며 투자·세금·법률 판단이 아니라는 안내를 함께 표시합니다.

같은 날 '끝내다' 같은 일반 단어 검색에 결과가 없다는 사용자 확인을 반영해, 산업·직무 공통 업무 용어 42개를 더하고 용어마다 우리말 뜻 검색어(`keywords`)를 달아 뜻으로도 찾게 했습니다. 용어집에 없는 일반 단어는 국립국어원 표준국어대사전 검색으로 연결하고, 일반 국어 단어 자체는 용어집에 넣지 않습니다.

## 5. 입력 방식

네이버 사전과 다음 사전의 검색 경험을 참고합니다.

| 입력 | 예 | 결과 |
|---|---|---|
| 단어 질문 | `LTV`, `엘티브이`, `고객 생애 가치` | 그 용어의 사전 항목 하나 |
| 목적형 요청 | `입사 첫 주에 알아야 할 용어`, `면접 전에 볼 지표` | 중요도 순 용어 10개, `더 보기`로 다음 10개 |

- 표제어, 원어, 약어, 한글 이름과 흔한 별칭(예: `엘티브이`)으로 모두 찾을 수 있게 합니다.
- 첫 버전은 AI 없이 동작하므로, 목적형 요청은 자주 쓰는 목적 버튼(입사 첫 주, 면접 준비, 지표 이해 등)과 핵심 낱말 일치로 처리합니다. 자유로운 문장 이해는 AI 보충 단계에서 넓힙니다.

## 6. 결과 형식

### 단어 항목

사전 한 항목에는 다음을 보여 줍니다.

1. 표제어와 난이도(입문·실무·심화)
2. 원어·약어 풀이: `LTV` → Lifetime Value, 고객 생애 가치
3. 쉬운 뜻: 한두 문장
4. 계산식·지표 공식: 지표인 경우에만. 예: `전환율 = 구매 수 ÷ 방문 수 × 100`
5. 실무 예문: 회의나 메신저에서 실제로 쓰는 말투의 문장 1~2개
6. 관련어·헷갈리는 말: 함께 알면 좋은 용어와 차이. 예: `GMV`와 `매출`
7. 출처와 확인 날짜

### 뜻이 여러 개인 단어

같은 단어가 산업이나 직무마다 뜻이 다르면 사전처럼 번호를 붙입니다. 사용자가 고른 산업과 직무의 뜻을 ①로 맨 위에 두고, 다른 뜻은 ②, ③으로 아래에 둡니다. 예를 들어 `전환`은 마케팅에서는 구매 전환, 기획에서는 화면 전환을 뜻할 수 있습니다.

### 목적형 묶음

- 고른 산업과 직무에 맞는 용어를 중요도 순으로 10개 보여 줍니다.
- 각 용어는 표제어, 난이도와 쉬운 뜻 한 줄만 보여 주고, 누르면 단어 항목을 엽니다.

## 7. 출처 원칙

- 1순위: 공공기관, 협회, 제품 공식 도움말(예: Google Analytics 도움말) 같은 공식 문서
- 2순위: INSIGHT 목록에 있는 기업 기술 블로그
- 뜻마다 출처 제목, 주소와 확인 날짜를 붙입니다.
- 출처를 찾지 못한 뜻은 `확인 필요`로 표시하고 확정된 정의처럼 쓰지 않습니다.
- 금융, 법률, 의료와 맞닿은 용어는 학습용 설명으로만 쓰고 판단이나 조언으로 표현하지 않습니다.

## 8. 기록과 복습

| 기능 | 동작 |
|---|---|
| 내 단어장 | 단어 항목에서 `저장`을 누르면 단어장에 모입니다. 새록이 공통 반응 `저장`과 같은 뜻입니다 |
| 오늘의 용어 | 첫 화면에 하루 한 개를 보여 줍니다. 고른 산업과 직무에서 아직 보지 않은 용어를 입문 → 실무 → 심화 순서로 고릅니다 |
| 아직 없는 용어 | 용어집에 없는 단어를 검색하면 기록해 두고, 목록을 내보내 다음 용어집 추가에 씁니다 |

첫 버전의 단어장, 본 용어와 아직 없는 용어 기록은 사용자의 브라우저에 저장합니다. 다른 기기와 공유되지 않으며, 필요해지면 파일 저장 방식으로 바꿉니다.

## 9. 용어 데이터

검수한 기본 용어집을 먼저 만들고, AI 보충은 다음 단계에 붙입니다.

- 규모: 산업×직무 한 칸에 30개(입문 10, 실무 15, 심화 5 정도). 2개 산업 × 4개 직무로 최대 240개이며, 여러 칸에 걸치는 용어는 하나로 합칩니다.
- 위치: `fruits/17-saerok-dictionary/data/catalog.json`(산업과 직무 목록), `fruits/17-saerok-dictionary/data/terms.json`(용어)

용어 하나의 형식 초안은 다음과 같습니다.

```json
{
  "id": "ltv",
  "term": "LTV",
  "original": "Lifetime Value",
  "korean": "고객 생애 가치",
  "aliases": ["엘티브이", "CLV"],
  "senses": [
    {
      "industries": ["ecommerce", "platform"],
      "roles": ["marketing", "data"],
      "level": "실무",
      "importance": 5,
      "definition": "고객 한 명이 거래 기간 전체에 걸쳐 회사에 가져다줄 것으로 기대하는 가치입니다.",
      "formula": "LTV = 평균 주문 금액 × 구매 빈도 × 고객 유지 기간",
      "examples": ["이번 캠페인은 CAC는 높지만 LTV가 커서 해 볼 만해요."],
      "sources": [{"title": "출처 제목", "url": "https://...", "kind": "official", "checked_at": "2026-10-15"}],

    }
  ],
  "related": [{"term": "CAC", "note": "고객 한 명을 데려오는 데 드는 비용. LTV와 함께 봅니다."}],

```

위 예시의 문장과 공식은 형식 설명용이며, 실제 용어집에 넣을 때는 출처를 확인해 다시 씁니다.

## 10. 화면

저장소 안 HTML 파일(`fruits/17-saerok-dictionary/web/index.html`)을 브라우저로 엽니다. 저장소를 2026-10-15 공개로 바꾸고 GitHub Pages(https://jhheo51-arch.github.io/saeroki/)로도 배포합니다.

`산업·직무 선택 → 오늘의 용어 → 검색창(단어 또는 목적) → 사전 항목 또는 10개 묶음 → 저장 → 내 단어장`

## 11. 완료 기준

첫 완성본은 다음을 모두 만족해야 합니다.

- 산업 2개와 직무 4개를 데이터 파일 목록에서 고를 수 있음
- 산업×직무 한 칸마다 출처를 붙인 용어 30개
- 표제어, 원어, 약어, 한글 이름, 별칭으로 검색됨
- 단어 항목에 쉬운 뜻, 원어·약어 풀이, 계산식(해당 시), 실무 예문, 관련어·헷갈리는 말, 출처 표시
- 뜻이 여러 개면 고른 산업·직무의 뜻이 ①로 먼저 나옴
- 목적형 요청에 중요도 순 10개와 `더 보기`
- 입문·실무·심화 난이도 표시
- 출처 없는 뜻은 `확인 필요` 표시
- 내 단어장 저장과 오늘의 용어
- 용어집에 없는 단어 기록과 내보내기

## 12. 성공 기준

초기 사용자 확인에서 다음을 관찰합니다.

1. 회의나 공고에서 본 단어를 새록 사전에서 찾아 바로 이해합니다.
2. 오늘의 용어를 일주일 동안 매일 확인합니다.
3. 단어장에 저장한 용어를 다시 열어 봅니다.
4. 뜻풀이에 붙은 출처를 신뢰할 수 있습니다.

이 기준은 초기 가설이며, 실제 사용 후 조정합니다.
